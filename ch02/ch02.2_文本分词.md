## 1. 下载示例文本

```python
import os
import urllib.request

url = 'https://raw.githubusercontent.com/xuweicn1/GPT-From-Zero/refs/heads/ch02/ch02/the-verdict.txt'
file_path = 'the-verdict.txt'

# 下载文件（如果不存在）
if not os.path.exists('the-verdict.txt'):
    urllib.request.urlretrieve(url, file_path)

# 读取文件内容
with open(file_path, 'r') as f:
    raw_text = f.read()

# 查看文本长度
len(raw_text)  # 输出：20479
```

**目标**：将 20479 个字符分割成独立的单词和特殊字符，方便之后转换为嵌入向量。

---

## 2. 正则表达式分词

### 基础示例

```python
import re

text = 'Hello, world. This, is a test.'
result = re.split(r'(\s)', text)
# 输出：['Hello,', ' ', 'world.', ' ', 'This,', ' ', 'is', ' ', 'a', ' ', 'test.']
```

### 改进：按标点符号分割

```python
# 按逗号、句号、空格分割
result = re.split(r'([,.]|\s)', text)
# 输出包含空字符串，需要过滤
```

### 扩展：支持更多标点符号

```python
text = 'Hello, world. Is This-- is a test?'
result = re.split(r'([,.:;?_!"()\']|--|\s)', text)
```

### 过滤空字符串

```python
# 去除空白项
result = [item.strip() for item in result if item.strip()]
# 输出：['Hello', ',', 'world', '.', 'Is', 'This', '--', 'is', 'a', 'test', '?']
```

## 3. 处理完整文本

```python
# 对完整文本进行分词
processed = re.split(r'([,.:;?_!"()\']|--|\s)', raw_text)
processed = [item.strip() for item in processed if item.strip()]

len(processed)  # 输出：4690

# 查看前30个词
print(processed[:30])
```

**输出示例**：
```
['I', 'HAD', 'always', 'thought', 'Jack', 'Gisburn', 'rather', 'a', 'cheap', 
 'genius', '--', 'though', 'a', 'good', 'fellow', 'enough', '--', 'so', 'it', 
 'was', 'no', 'great', 'surprise', 'to', 'me', 'to', 'hear', 'that', ',', 'in']
```

## 关键要点

| 步骤 | 说明 |
|------|------|
| 1. 下载文本 | 从 GitHub 获取示例文本（20479 字符） |
| 2. 定义分词规则 | 使用正则表达式匹配标点符号和空格 |
| 3. 分割文本 | `re.split()` 保留分隔符 |

---

## 正则表达式说明

```python
r'([,.:;?_!"()\']|--|\s)'
```

| 部分 | 匹配内容 |
|------|----------|
| `[,.:;?_!"()\']` | 单个标点符号 |
| `--` | 双破折号 |
| `\s` | 空白字符（空格、换行等） |
| `()` | 捕获分组，保留分隔符 |
```
