
# 环境配置指南

## 一、Python 安装

### 下载安装
1. 访问官网：https://www.python.org/downloads/
2. 下载对应系统的安装包
3. 按提示完成安装（**记得勾选「Add Python to PATH」**）

### 验证安装
```bash
python -V
# 正常输出：Python 3.x.x
````

***

## 二、虚拟环境管理

### 创建虚拟环境

```bash
# 在项目根目录执行
python -m venv .venv
```

### 激活虚拟环境

| 操作系统          | 激活命令                        |
| ------------- | --------------------------- |
| Windows       | `.venv\Scripts\activate`    |
| Linux / macOS | `source .venv/bin/activate` |

### 退出虚拟环境

```bash
deactivate
```

## 五、更换 Pip 源（国内加速）

### 问题说明

默认官方源位于国外，国内下载可能遇到：

*   ⏱️ 速度慢
*   🔄 连接不稳定
*   ⚠️ 大文件（PyTorch、TensorFlow）容易超时

### 临时使用（单次）

```bash
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

### 永久配置（推荐）

#### 方式一：命令行配置（最快）

```bash
# 配置腾讯源
pip config set global.index-url https://mirrors.cloud.tencent.com/pypi/simple
pip config set global.trusted-host mirrors.cloud.tencent.com
```

#### 方式二：手动创建配置文件

**Windows**

1.  打开 `%APPDATA%` 目录
2.  新建 `pip` 文件夹
3.  创建 `pip.ini` 文件，内容如下：

```ini
[global]
index-url = https://pypi.tuna.tsinghua.edu.cn/simple
trusted-host = pypi.tuna.tsinghua.edu.cn
```

**Linux/macOS**

```bash
mkdir -p ~/.pip
vi ~/.pip/pip.conf
```

内容同上。

### 配置验证

```bash
pip config list
# 输出示例：global.index-url='https://mirrors.cloud.tencent.com/pypi/simple'

pip config debug
# 查看配置文件是否存在
```

### 清除缓存并重新安装

```bash
pip cache purge
pip install -r requirements.txt
```

## 六、使用 UV（高性能替代方案）

### 安装 UV

```bash
pip install uv
```

### 常用命令

```bash
uv init                          # 初始化项目（生成 pyproject.toml）
uv add -r requirements.txt       # 从 requirements.txt 导入依赖
uv sync                          # 同步环境与锁文件
uv run pip list                  # 查看已安装包
uv tree                          # 查看依赖树
uv run jupyter lab               # 启动 Jupyter
```

## 七、常见问题

### Q1：pip 安装速度慢？

```bash
# 使用国内镜像源
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

### Q2：虚拟环境激活失败？

*   **Windows**：可能需要管理员权限，或执行 `Set-ExecutionPolicy RemoteSigned -Scope CurrentUser`
*   **Linux/macOS**：检查 `.venv` 目录是否存在

### Q3：版本冲突？

严格按照 `requirements.txt` 中的版本范围安装，避免兼容性问题。
