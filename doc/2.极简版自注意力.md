
## 🎯 极简版自注意力（10行核心代码）

```python
import torch
import torch.nn.functional as F

def simple_self_attention(x):
    # x shape: (seq_len, d_model)
    scores = x @ x.T                    # 1. 计算相似度（注意力分数）
    weights = F.softmax(scores, dim=-1) # 2. 归一化成注意力权重
    output = weights @ x                # 3. 加权求和得到输出
    return output

# 测试：3个词，每个词4维
x = torch.randn(3, 4)
output = simple_self_attention(x)
print(output.shape)  # (3, 4) - 输出和输入形状相同
```

**这就是注意力机制的核心！** 无论多复杂的Transformer，本质都是这三步。

### 版本2：带Q/K/V（有训练参数）
```python
import torch
import torch.nn as nn

class SelfAttention(nn.Module):
    def __init__(self, d_in, d_out):
        super().__init__()
        self.W_q = nn.Linear(d_in, d_out, bias=False)
        self.W_k = nn.Linear(d_in, d_out, bias=False)
        self.W_v = nn.Linear(d_in, d_out, bias=False)
    
    def forward(self, x):
        Q = self.W_q(x)  # queries
        K = self.W_k(x)  # keys
        V = self.W_v(x)  # values
        
        scores = Q @ K.T                    # 注意力分数
        weights = torch.softmax(scores / (K.shape[-1]**0.5), dim=-1)
        return weights @ V                  # 上下文向量

# 使用
x = torch.randn(6, 3)   # 6个词，每个3维
attn = SelfAttention(3, 2)  # 输出变成2维
output = attn(x)
print(output.shape)  # (6, 2)
```

### 版本3：因果注意力（GPT用的）
```python
class CausalSelfAttention(nn.Module):
    def __init__(self, d_in, d_out, context_len):
        super().__init__()
        self.W_q = nn.Linear(d_in, d_out, bias=False)
        self.W_k = nn.Linear(d_in, d_out, bias=False)
        self.W_v = nn.Linear(d_in, d_out, bias=False)
        # 创建下三角掩码（屏蔽未来信息）
        self.register_buffer('mask', torch.tril(torch.ones(context_len, context_len)))
    
    def forward(self, x):
        Q, K, V = self.W_q(x), self.W_k(x), self.W_v(x)
        scores = Q @ K.T
        
        # 关键：把未来的位置设为负无穷
        scores = scores.masked_fill(self.mask == 0, float('-inf'))
        
        weights = torch.softmax(scores / (K.shape[-1]**0.5), dim=-1)
        return weights @ V

# 测试因果性
x = torch.randn(4, 3)  # 4个词
causal_attn = CausalSelfAttention(3, 2, 4)
output = causal_attn(x)
print(output.shape)  # (4, 2)
```

## 💡 常见问题解答（初级程序员必读）

### Q1: 为什么要除以 `sqrt(d_k)`？
**A**: 防止点积结果太大导致softmax梯度消失。你可以试试去掉它，会发现权重变得很极端（接近one-hot）。

### Q2: `@` 运算符是什么？
**A**: 矩阵乘法。`x @ y.T` 等价于 `torch.matmul(x, y.T)`

### Q3: 为什么输出形状和输入相同？
**A**: 注意力是一种"变换"，不改变序列长度。每个词的新表示都融合了其他词的信息。

### Q4: 训练时这些权重怎么更新？
**A**: PyTorch的 `nn.Linear` 会自动跟踪梯度。你只需要：
```python
optimizer = torch.optim.Adam(model.parameters())
loss = mse_loss(output, target)
loss.backward()  # 自动计算梯度
optimizer.step() # 更新W_q, W_k, W_v
```

### Q5: 多头注意力是什么？
**A**: 就是并行运行多个注意力（版本2），然后把结果拼起来。可以理解为"多个专家从不同角度分析"。
