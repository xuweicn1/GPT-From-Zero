### ✅ **必须掌握**（日常工作80%场景）

#### 1. 理解注意力的**输入输出**
```python
# 你必须知道的接口知识
输入: (batch_size, seq_len, d_model)  # 一批文本，每段L个词，每个词D维
输出: (batch_size, seq_len, d_model)  # 形状不变，但每个词融合了上下文

# 实际例子
from transformers import AutoModel
model = AutoModel.from_pretrained("bert-base-uncased")
outputs = model(input_ids)  # 你要清楚outputs.last_hidden_state的含义
```

**你需要能回答**：
- 为什么输入输出形状相同？
- 如何处理不同长度的序列（padding/attention_mask）？
- 如何提取[CLS] token或平均池化作为句子表示？

#### 2. 知道**何时用哪种注意力**
| 任务 | 用的注意力 | 为什么 |
|------|-----------|--------|
| 文本分类 | 双向自注意力 | 需要看完整上下文 |
| 文本生成(GPT) | 因果注意力 | 不能看到未来 |
| 翻译(BERT→GPT) | 交叉注意力 | 编码器和解码器之间 |
| 长文档处理 | 稀疏注意力 | 降低计算量 |

#### 3. 能**调试常见问题**
```python
# 典型问题1: 显存不足
# 原因: attention的O(n²)复杂度
# 解决: 减小seq_len、使用gradient checkpointing、改用稀疏注意力

# 典型问题2: 生成长文本时重复
# 原因: 注意力过于集中在局部
# 解决: 调整temperature、使用repetition_penalty

# 典型问题3: 长距离依赖丢失
# 原因: 位置编码限制
# 解决: 使用RoPE、ALiBi或增加上下文长度
```

#### 4. 会**调优注意力相关超参数**
```python
# RAG应用中的常见调优
{
    "temperature": 0.7,      # 注意力权重分布的平滑度
    "top_p": 0.9,            # 核采样，限制注意力范围
    "repetition_penalty": 1.1, # 降低重复token的注意力
    "num_beams": 4,          # 束搜索，多路径注意力
}
```

### ⚠️ **需要了解**（偶尔用到，但重要）

#### 1. 注意力的**变体和效率优化**
```python
# 你应该知道这些概念存在，但不需实现
- Flash Attention: 如何节省显存
- Sparse Attention: 如何降低O(n²)复杂度
- Sliding Window Attention: 如何限制注意力范围
- Multi-Query Attention: 如何加速推理
```

**面试可能会问**：
- "如果输入序列很长(100k tokens)，标准自注意力有什么问题？"
- "你会用什么技术来降低注意力计算成本？"

#### 2. **位置编码**的影响
```python
# 你不需要实现，但要理解影响
绝对位置编码（原始Transformer）: 适合固定长度
相对位置编码（RoPE）: 外推性更好，LLaMA在用
ALiBi: 不需要学习位置参数
```

**实际影响**：
- 选择模型时考虑其支持的最大长度
- 微调时如果改变序列长度，位置编码如何处理

#### 3. **注意力可视化**用于调试
```python
# 你不需要实现注意力计算，但要知道怎么用它调试
from transformers import AutoTokenizer, AutoModel

model = AutoModel.from_pretrained("bert-base-uncased")
outputs = model(input_ids, output_attentions=True)
attentions = outputs.attentions  # 各层的注意力权重

# 检查: 
# - 注意力是否过于均匀（没学到有用信息）
# - 是否过度集中在[SEP]等特殊token
# - 层间注意力分布是否合理
```
