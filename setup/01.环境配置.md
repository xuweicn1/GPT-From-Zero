# 环境配置指南

## 一、Python 安装

### 下载安装

*   访问官方网站：<https://www.python.org/downloads/>
*   下载对应系统的 Python 安装包
*   按提示完成安装

### 验证安装

```bash
python -V
```

正常输出示例：`Python 3.x.x`

***

## 二、虚拟环境管理

### 创建虚拟环境（项目根目录执行）

```bash
python -m venv .venv
```

### 激活虚拟环境

| 操作系统          | 激活命令                        |
| ------------- | --------------------------- |
| Linux / macOS | `source .venv/bin/activate` |
| Windows       | `.venv\Scripts\activate`    |

### 退出虚拟环境

```bash
deactivate
```

***

## 三、安装依赖包

### 快速安装

```bash
pip install -r requirements.txt
```

### 一键配置（可选）

```bash
# 克隆项目后执行
python -m venv .venv
.venv\Scripts\activate
#  linux 用 source .venv/bin/activate  
pip install -r requirements.txt
```

| 包名         | 版本要求    | 使用章节             | 说明                       |
| ---------- | ------- | ---------------- | ------------------------ |
| torch      | ≥2.2.2  | 通用               | 深度学习框架（macOS Intel 特殊版本） |
| jupyterlab | ≥4.0    | 通用               | 交互式开发环境                  |
| tiktoken   | ≥0.5.1  | ch02, ch04, ch05 | OpenAI 分词器               |
| matplotlib | ≥3.7.1  | ch04, ch06, ch07 | 数据可视化                    |
| tensorflow | ≥2.16.2 | ch05, ch06, ch07 | 深度学习框架（macOS Intel 特殊版本） |
| tqdm       | ≥4.66.1 | ch05, ch07       | 进度条显示                    |
| numpy      | ≥1.26   | 通用               | 数值计算库                    |
| pandas     | ≥2.2.1  | ch06             | 数据处理                     |
| psutil     | ≥5.9.5  | ch07             | 系统监控                     |

> **注意**：`torch`、`tensorflow` 在 macOS Intel 芯片上有专门的版本约束，其他系统使用通用版本即可。`psutil` 通常会作为 torch 的依赖自动安装。

## 五、更换PIP源

### 当前使用的源

| 项目    | 内容                        |
| ----- | ------------------------- |
| 默认源地址 | `https://pypi.org/simple` |
| 位置    | 国外服务器                     |

### 影响

使用官方源在国内下载可能会：

*   ⏱️ 下载速度慢
*   🔄 连接不稳定
*   ⚠️ 大文件（如 PyTorch、TensorFlow）容易超时

### 建议配置国内镜像源

### 临时使用（单次安装）

```bash
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

### 永久配置（推荐）

#### 方法1

```bash

# 配置腾讯源
pip config set global.index-url https://mirrors.cloud.tencent.com/pypi/simple

# 配置信任主机（可选，避免警告）
pip config set global.trusted-host mirrors.cloud.tencent.com

```

#### 方法2

##### Windows 系统

1. 在文件资源管理器地址栏输入 %APPDATA%，回车并进入该目录。

2. 新建一个名为 pip 的文件夹，在里面新建一个文本文档，重命名为 pip.ini（如果看不到后缀，可以打开"显示文件扩展名"后再改）。
3. 右键 pip.ini，用记事本编辑，并粘贴以下内容：
    
    ```
    ini
    [global]
    index-url = https://pypi.tuna.tsinghua.edu.cn/simple
    trusted-host = pypi.tuna.tsinghua.edu.cn
    macOS / Linux 系统
    ```

##### Linux 系统


1. 打开终端，运行以下命令创建配置文件目录和文件：

    ```
    bash
    mkdir -p ~/.pip
    vi ~/.pip/pip.conf
    ```

2. 在打开的文件中粘贴以下内容：
    ```
    ini
    [global]
    index-url = https://pypi.tuna.tsinghua.edu.cn/simple
    trusted-host = pypi.tuna.tsinghua.edu.cn
    ```


### 配置后验证

```bash
pip config list
```

输出示例：

    global.index-url='https://mirrors.cloud.tencent.com/pypi/simple'
    global.trusted-host='mirrors.cloud.tencent.com'

### 再次查看配置

```bash
pip config debug
```

此时会显示：

    user:
      C:\Users\me\AppData\Roaming\pip\pip.ini, exists: True  # 配置文件已创建

## 六、常见问题

### Q1：pip 安装速度慢？

```bash
# 使用国内镜像源加速
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

### Q2：虚拟环境激活失败？

*   **Windows**：可能需要管理员权限或执行 `Set-ExecutionPolicy RemoteSigned`
*   **Linux/macOS**：检查 `.venv` 目录是否存在

### Q3：版本冲突？

建议严格按照 `requirements.txt` 中的版本范围安装，避免兼容性问题。



## 七、使用UV

### 安装UV

`pip install uv`


```bash
# 如果没有 pyproject.toml，先初始化
uv init

# 从 requirements.txt 导入所有依赖
uv add -r requirements.txt

# 根据 pyproject.toml 和 uv.lock 同步环境
uv sync

# 查看已安装的包
uv run pip list

# 或使用 uv tree 查看依赖树
uv tree

```
